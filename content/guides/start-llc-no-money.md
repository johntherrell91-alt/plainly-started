---
title: "Can I start an LLC with no money? A realistic cost breakdown"
date: 2026-10-14
---
Short answer: **not with $0.** Every state charges a filing fee. But you can keep it close to the state minimum.

| Item | Cost |
|---|---|
| State filing fee | Required; varies by state (e.g. [$300 in Texas](https://www.sos.state.tx.us/corp/forms/205_boc.pdf)) |
| EIN | **Free** from the [IRS](https://www.irs.gov/businesses/small-businesses-self-employed/get-an-employer-identification-number) |
| Registered agent | Free if you serve yourself |
| Operating agreement | Free templates exist; attorney review optional |
| Formation service | Optional, e.g. <a href="#AFFILIATE-zenbusiness" rel="sponsored nofollow">ZenBusiness</a> <!-- PLACEHOLDER affiliate link: replace after approval --> |
| Ongoing state fees | Varies (e.g. [California $800/yr](https://www.ftb.ca.gov/file/business/types/limited-liability-company/index.html)) |

## If money is tight
Start as a sole proprietor (no state fee) and form the LLC once revenue justifies it.
