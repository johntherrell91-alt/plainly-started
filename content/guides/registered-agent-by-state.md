## The same everywhere
- Every state requires your LLC to have a registered agent with a **physical address in that state** who's available during business hours.
- You can usually be your own agent if you live in the state.

## What varies
- **Fees for naming or changing an agent.** Florida, for example, charges a $25 registered agent designation fee at formation and $25 to change agents ([Florida fees](https://dos.fl.gov/sunbiz/forms/fees/llc-fees/)). Wyoming charges $350 to reinstate an LLC that lost its registered agent ([Wyoming schedule](https://sos.wyo.gov/Business/Docs/BusinessFees.pdf)).
- **Terminology.** Some states say "statutory agent" or "agent for service of process".
- **Multi-state.** Registering in a second state means you need an agent there too.

## When a paid agent makes sense
